# 文件操作客户端和服务端

目标：在 SDK 中提供无第三方运行库依赖的 C/TCP 文件下载工具，电脑和 i.MX6ULL 均可运行。

接口：`file_server DIRECTORY [PORT]`，`file_client IP [PORT] cp REMOTE_PATH DESTINATION`；端口默认 9000。远端路径相对共享目录，兼容 `SERVER-DIR/` 前缀。目标是已有目录时使用远端文件名，否则使用指定文件名，覆盖已有普通文件。

服务端使用 `openat` 逐级解析共享目录内的路径，拒绝绝对路径、`..` 和符号链接。TCP 协议使用固定版本、命令号、明确长度及网络字节序，支持空文件和大文件。每个连接独立子进程处理；读写超时后关闭连接。客户端在目标目录生成临时文件，完整接收、刷新成功后再重命名，失败保留原目标。

目录：`src/common.[ch]` 负责协议及网络读写，`src/server.c` 负责共享目录和连接处理，`src/client.c` 负责命令解析与本地文件保存，`tests/test_transfer.py` 负责真实 TCP 集成测试。提供 Makefile、封装函数的 build/clean/test 脚本和中文 README；源码及脚本使用英文提示。
